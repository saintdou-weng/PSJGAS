# VRT 總務工作台 · PSJGAS

同一入口操作 **SEC、GasCheck、GASExp 的 23 個模組**（含 8 個 SEC 模組）。首頁整合總覽、待辦、紀錄、分析；可依日／週／月／年切換，用前後期與下拉選單快速查找。支援繁中、英文及高棉文。原本的稽核評鑑保留在 `legacy.html`，可從側欄「原稽核評鑑」開啟。

工作台的上傳、下載、JSON 匯入與備份、CSV 匯出使用獨立的 **PSJGA_CORE 總表**。同一原始單號按更新時間合併，舊版或同版資料不會蓋掉已刪除紀錄；其他人先上傳時須先下載最新版本。各原模組的新增、修改、刪除、Excel、照片、核可及既有雲端，仍可從模組卡片打開原頁操作。舊資料不會自動搬進總表。

`index.html` 是可直接開啟的完整首頁，無前端相依套件、外部字型或圖表 CDN。預設顯示正式總表未載入，只有主動點「查看範例」才顯示示範資料。

部署 `PSJGA_CORE` 並啟用群組指令後，在 PSJGA 群組輸入 `/psjga`，@psjga_bot 會回覆「開啟總務平台」按鈕。如果 Telegram 未把一般指令交給這個 Bot，使用 `/psjga@psjga_bot`。
