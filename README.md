# VRT 總務工作台 · PSJGAS

側欄依門禁與安全、環境與巡檢、宿舍與資產、採購與費用分組，單擊即可開啟 **SEC、GasCheck、GASExp 的 23 個業務頁**。每頁上方可在「原系統作業」與「總表紀錄」之間切換。總覽、待辦和分析可用日／週／月／年查詢，並保留繁中、英文、高棉文和原稽核評鑑。

「總表紀錄」可新增、編輯、儲存、刪除與還原，亦可下載 CSV 範本、匯入 JSON／CSV、匯出 Excel 可開啟的 CSV 或備份 JSON。儲存會直接寫入 **PSJGA_CORE**。匯入後可先核對，再上傳本業務或全部變更。開啟已授權的工作台會下載一次，切換頁籤與篩選使用同一份資料；手動下載時，雲端版本沒變就不重傳紀錄。

同一業務與單號只保留一筆；舊檔不會覆蓋新資料或復活已刪除紀錄。兩台裝置同時修改一筆時，先下載再選擇要保留的版本。原系統的舊紀錄、核可與照片仍在各自的業務頁；這版不會搬移或覆寫原系統資料。

`index.html` 是可直接開啟的完整首頁，無前端相依套件、外部字型或圖表 CDN。預設顯示正式總表未載入，只有主動點「查看範例」才顯示示範資料。

部署 `PSJGA_CORE` 並啟用群組指令後，在 PSJGA 群組輸入 `/psjga`，@psjga_bot 會回覆「開啟總務平台」按鈕。如果 Telegram 未把一般指令交給這個 Bot，使用 `/psjga@psjga_bot`。
